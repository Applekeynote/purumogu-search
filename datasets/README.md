# 実測シミュレーションデータ

`sample.jsonl` は、公開モデルで実際にUnityを動かした1エピソードの入出力監査ログ。3バッチ分のセンサーイベント・ゲート指令・ACK・候補分布を含む。正解座標や形状ラベルは含めない。`sample-expected.json`でリプレイ結果を検査できる。

全量の生イベントは大きいためGitに含めない。再生成はリポジトリのルートで次を実行する。

```powershell
.\scripts\Run-Experiments.ps1 -Collect
```

学習用収集は5族×18マップ×6通りの開始行動で540エピソード、1エピソード3バッチ。map index 0-9がTRAIN、10-12がVALID、13-17が収集時のTEST。公平な行動比較ではさらに13-22の10マップ/族を使用し、計50個の未使用マップに拡張する。

これは設計書の推奨70/15/15比率とは異なる。小規模な学習を前提に、VALIDと未使用マップの件数を確保した。比率ではなく、map単位の完全分離を実装上の必須条件として検査する。TESTを使って温度・しきい値・コードブックを変更しない。

`manifest.json` はファイルのSHA-256、実行版、物理step、収集所要時間、シード方式を記録する。`generated/v1/observations.jsonl`と`truth.jsonl`は別経路。推論サービスにtruthのパスを渡さない。GHOST-FLOW / Random / Fixedは入口3×隊形2から選び、すべて5個×3バッチ。FixedはCLUSTER、Passiveは同じ入口順で接地推力を無効にする。

通信欠損は受信側のスキャン単位で0/10/20/40%を欠落させる簡略模型。未受信peerのIDや真の距離は通知しない。ノード時計のオフセットとドリフトを付けるが、集計は基幹側の受信時刻を使う。
