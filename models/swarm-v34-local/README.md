# 3.4の形状非依存プロファイル

音響・距離の係数と学習来歴は`swarm-v3-bootstrap`を引き継ぐ。`local_surface_completion=true`を追加し、`prototypes`を空にした。新形状を旧15形状へ無理に分類して埋めることを避けるためで、音響係数を新しい15シーンで再学習したチェックポイントではない。

幾何推論は、生の距離・姿勢に基づく逐次占有、局所平面の補完、床支持を持つ3D経路を使用する。シーンIDや正解地形、人の正解位置をサーバーへ送らない。入力契約は2.0のままで、旧モデルの当該フラグは既定でfalseとなる。

新しい30シーン構成の95%受入条件を満たしたモデルとして配布していない。[検証と制限](../../docs/complex-mapping-v34.md)を参照。
