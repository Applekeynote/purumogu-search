# ぷるもぐサーチ3.5 / 完成範囲と到達精度

2026年11月1日。利用者の指定に従い、現時点で動作確認できた機能とモデルを成果物として完了した。追加学習・収集は停止し、未完了のモデルは同梱していない。

## 起動する

Windows版は `PurumoguSearch-Windows-v3.5.zip` 全体を展開し、`PurumoguSearch.exe` を開く。Unity・Rust・Python・CUDAの導入は不要。アプリが同梱CPU推論を起動し、終了時に停止する。

Unity Hubでは `PurumoguSearch-Unity-v3.5.zip` を展開してプロジェクトを追加する。Unity 6000.4.1f1で `Assets/Scenes/Main.unity` を開き、再生する。この配布物には推論サービス・モデルも含む。

ローカルの原本プロジェクトはリポジトリ内の `unity`。モデルの原本は `models/swarm-v35-generic` に保存した。GitHubのソースからビルドする場合はREADMEの手順を使う。

## 完成した機能

全長約7cmの球体関節と二つの円錐形部品を持つノードを、24・36・48台で切り替える。屈曲・回転、先端と球体の連結・分離、重力・接触、上空と複数の破損開口からの散布に対応する。人物の位置は独立に変え、左上の赤球で正解を確認できる。

地震・斜面崩壊・浸水、非長方形、多層構造を含む36シーンを用意した。部分崩落では、次の3例を含む。

1. **C01・床が重なる崩落**：残存床と落下床片の下に薄い空隙が残る。
2. **C03・V字落下の三層棟**：L字の外形と傾いた床で、上下の見通しが変わる。
3. **C04・欠損がずれる三層棟**：各階の開口・瓦礫・浸水・ガス反応が重なる。

右上は黒背景と緑の輪郭格子で、観測の進行に合わせて形成する。推定補完は暗い破線、人候補は橙、ガスは赤、浸水は青。推論に人物・危険箇所の正解位置を渡さない。両3D画面はドラッグ回転とホイール拡縮に対応する。

## 何を学習し、どこまで到達したか

採用したR36は、506ケース・453世界で地図を学習した。2.5cmの細分格子と248世界の補助正解で、面の境界・層間の空隙を学ぶ。距離・姿勢・音響・温度の誤差は維持し、評価セルは5cmのまま。人物判定は426世界で学習し、探索には別に固定した学習済みモデルを使う。

**固定したVALID観測ログ54ケースでの比較**は以下のとおり。実探索を新たに動かした成績とは分ける。

| 対象 | 到達値 |
|---|---:|
| 地図IoU・全体平均 | 97.05% |
| 地図IoU・既知形状平均 | 97.12% |
| 地図IoU・未学習形状平均 | 96.87% |
| 最も低いエリアのIoU平均 | 94.43% |
| 人候補・適合率 / 再現率 | 各96.67% |
| 人物の対応数 / 誤検出 | 90人中87人 / 3件 |

**同梱構成で新たに動かした6ケースの360秒探索**では、既知4ケースの地図IoU平均96.49%、未学習2ケース93.86%。人物は18人中16人・誤検出1件で、適合率94.12%、再現率88.89%だった。120秒の記録も保存した。

追加の54ケース収集は22ケースの完了時点で終了した。未完了を含むため、この収集から全条件の成績は出していない。既存90ケースと部分崩落18ケースの最終TESTは未使用である。

## 検証と制限

36シーンのアプリで、開発ツールをPATHから外した環境でも実際の推論地図を返し、終了時に推論プロセスが停止することを確認した。PythonとRustの地図出力も、確認用入力で占有判定の不一致0セルだった。Windows・LinuxのCI、Rustのテスト・clippy、学習・評価分離と時間を打ち切った入力の検査を通している。

利点は、単体アプリで動かせることと、実観測・推定・正解評価を区別して比較できること。層状崩落を見た目だけでなく衝突・遮蔽へ反映している。

残る制限は、全エリアで3指標95%以上を確認していないこと、静的な崩落形状と模擬センサーによる検証であること、実災害の救助性能や構造安全性を実証していないことである。見えていない穴を一律に塞ぐ処理は行わず、本当の床欠損を塞いだ場合も誤りとして評価する。
