# ぷるもぐサーチ3.5 / 36シーン・CPU推論同梱

利用者の指定に従い、現時点で完成・動作確認できた機能をまとめた版です。追加学習と収集は終了し、完成済みのR36地図モデル・G75人物判定器・固定したR28探索モデルを同梱しました。

## 使い方

- **Windowsアプリ**：`PurumoguSearch-Windows-v3.5.zip` 全体を展開し、`PurumoguSearch.exe` を起動。Unity・Rust・Python・CUDAの導入は不要です。
- **Unity Hub**：`PurumoguSearch-Unity-v3.5.zip` を展開し、`PurumoguSearch-Unity-v3.5` フォルダーを追加。Unity 6000.4.1f1で `Assets/Scenes/Main.unity` を開いて再生します。推論サービス・モデルを同梱し、このプロジェクトからの再ビルドも確認しました。

## 含む機能

- 約7cmの関節ノード24・36・48台。球体と先端の連結・分離、屈曲・回転、重力・接触、上空と破損開口からの散布。
- 地震・斜面崩壊・浸水、多形状・多層を含む36シーン。部分崩落6種類は残存床・実際の欠損・落下床片・層状瓦礫を衝突と遮蔽にも使います。
- 観測に合わせて形成する緑の輪郭格子。推定は暗い破線、人候補は橙、ガスは赤、浸水は青。両3D画面のドラッグ回転・ホイール拡縮。
- アプリがCPU推論を自動起動・終了。開発ツールをPATHから外した環境で、実際の推論地図と終了処理を確認済みです。

## 学習と到達精度

R36は506ケース・453世界と、248世界の2.5cm補助正解を使って学習しました。人物判定は426世界です。センサーと誤差を維持し、評価セルは5cmとしています。

固定したVALID観測ログ54ケースでは、地図IoU平均97.05%、既知形状97.12%、未学習形状96.87%、最低エリア94.43%。人物は90人中87人・誤検出3件で、適合率・再現率とも96.67%でした。

同梱構成を新たに動かした6ケースの360秒探索では、地図IoU平均は既知4ケース96.49%、未学習2ケース93.86%。人物は18人中16人・誤検出1件（適合率94.12%、再現率88.89%）でした。

**全エリアで地図IoU・人物の適合率・再現率がすべて95%以上という合格を確認した版ではありません。** 54ケースの追加実探索は22ケース完了時に終了し、全条件の成績として採用していません。最終TEST108ケースは未使用です。有限の模擬環境での検証であり、実災害の救助性能や構造安全性を保証するものではありません。
