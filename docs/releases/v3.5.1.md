# ぷるもぐサーチ3.5.1 / サイズ変更できるウィンドウ

Windowsアプリをフルスクリーンから通常のウィンドウに変更しました。

- 枠や角をドラッグして、ウィンドウのサイズを変更できます。
- 右上のボタンで最大化し、元のサイズへ戻せます。
- タイトルバーをドラッグして、位置を移動できます。

初期サイズは最大1280×720。小さい画面では表示解像度の85%以内に収めます。旧版で保存されたフルスクリーン設定も、起動時にウィンドウへ切り替えます。起動後のサイズ変更を上書きする処理はありません。Unityプロジェクトにも同じ設定を反映しています。

Windows用ZIP全体を展開し、`PurumoguSearch.exe`を起動してください。Unity Hub用ZIPは展開したフォルダーを追加し、Unity 6000.4.1f1で開きます。

複数のアプリを並べて使いやすくなります。小さく縮めると4分割画面の文字も小さくなるため、文字を読む際は拡大または最大化してください。両3Dビュー内のホイール操作は、従来どおりカメラのズームです。

36シーン・CPU推論モデル・到達精度は3.5と同じです。追加学習は行っていません。[完成範囲と精度](https://github.com/Applekeynote/purumogu-search/blob/v0.3.5/docs/v35-completion.md)を参照してください。

設定の根拠：[Unityのウィンドウサイズ変更設定](https://docs.unity3d.com/ja/current/ScriptReference/PlayerSettings-resizableWindow.html)。
