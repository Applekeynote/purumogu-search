# 部分崩落と層構造を含む探索条件

2026年11月1日、利用者の指示で学習を再開し、部分崩落した建物を追加した。センサー、位置・姿勢の誤差、7cmの機体、24・36・48台、上空と複数の破損開口からの投入を維持する。合格判定は360秒。120秒時点も残す。

## 再現するもの

床の残存部、欠損、落下床片、それを支える瓦礫、層間の空隙を別の衝突形状で作る。上階の欠損位置をずらすため、上から一度見ただけでは下階全体を観測できない。新シーンでは、崩落後に残る層の間隔を25〜32cmの範囲で独立に変える。通常の建物の階高をこの値とみなすものではない。既存シーンの高さは変えていない。欠損を描いた画像を重ねる方法ではなく、距離観測の遮蔽、音響・温度の遮蔽、接触、重力に同じ形状が使われる。

具体的には、次の3例を含む。

1. 床が重なる崩落。残った床の横に落下床片と層状の瓦礫があり、その下には薄い空隙が残る。
2. 片側落下とV字落下。傾いた床の下にくさび状の空隙があり、中央の落下部が奥の反応を遮る。
3. 複数階の部分崩落。各階の欠損がずれ、残存床、落下片、上下の空洞が立体的に重なる。非長方形の外形、残留水、ガス反応、無人の負例も含む。

床の崩落形状は、[FEMAのUS&R教材](https://www.fema.gov/pdf/emergency/usr/module1c2.pdf)と[インド国家災害対応部隊のCSSR教材](https://ndrf.gov.in/sites/default/files/CSSR%20Instructor%27s%20Guide%20-%20Lesson%203%20-%20Construction%20Materials%2C%20Structures%20and%20Damage%20Types.pdf)に示される床の重なり、片側落下、V字落下を参考にした。教材は形状の参考であり、本モデルの推論精度の根拠ではない。

これは崩落後の探索環境を作るもので、荷重・鉄筋の破断・耐力低下から崩壊過程を予測する構造解析ではない。床片と支持瓦礫は探索中は静的とし、旧シーンの余震による可動片は維持する。

## 学習と評価

追加TRAINは4種類×6個の独立した世界で24世界。台数は各8世界。VALIDは別の世界・人物位置で18ケース。最終TESTの追加分18ケースは計画だけを登録し、モデルを固定するまで収集しない。既存の最終TEST90ケースと併せて、追加条件も確認する。

推論へ渡すのは従来のセンサーパケットだけ。崩落の種類、何階のどの床を削ったか、床マスク、人物位置、正解の占有格子は渡さない。C05/C06をTRAINとして読み込ませた場合は、学習側と補助正解作成側で拒否する。

補完の目標は「穴を全部塞ぐこと」ではない。観測不足による欠測は周辺の観測から推定し、本当に抜けた床と空隙は空間として残す。実際の穴を床として埋めた場合は、全体の5cm占有IoUで偽陽性になる。評価格子、占有閾値0.6、人物の位置対応25cmは変えない。

## 形状と散布の検査

[階高も変える最終形状の検査結果](../reports/rescue/generic-v35/partial-collapse-variable-storeys-audit.json)は次の範囲を確認した。推論精度の成績ではない。[固定階高での先行検査](../reports/rescue/generic-v35/partial-collapse-geometry-audit.json)も残している。

- 6種類×4配置、24世界で、残存床・欠損・実際に高さが落ちた床片を確認。
- 同じ世界で人物位置だけを変えても、衝突形状の5cm占有格子は完全一致。人物は固体の瓦礫内へ配置されない。
- 6種類×3台数、18ケースで、モーターを止めた重力散布を17秒実行。全ケースで複数階に到達。最終形状では側面投入432台の喪失は0台だった。固定階高の先行検査では4台の喪失があり、両方の結果を残している。探索中の落下・喪失も精度評価から除外しない。
- 追加前の開発用4世界で、記録済みの正解占有格子と完全一致。既存エリアの形状を変えて易しくしていない。

初回の形状検査では、細いU字床端から床片がはみ出して支持面がない箇所を検出した。床片の横ずれ・狭い場所での回転を修正し、再検査した。これはデータ収集前の形状修正であり、悪い推論成績の除外・再試行ではない。初回ログも保存している。

## 利点と制限

利点は、上下の遮蔽や本当の床欠損を含めた補完を学べること、人物・危険反応が異なる階にある場合も評価できること、既存のセンサー条件と比較可能なことである。

制限は、静的な崩落形状と模擬センサーによる検証であること、現実の材質・反響・粉塵・機体挙動とのずれが残ること、有限の未学習シミュレーションで95%を確認しても任意の実災害現場で95%を保証できないことである。構造安全性の予測が必要な場合は、構造解析と実物の崩落模型によるセンサー検証を別に組み合わせる必要がある。

Unityのシーン選択と配布版3.5にはC01〜C06を追加済み。利用者の指定により現時点の成果で完了し、全件学習を終えたR36と、CPU単体推論・6ケースの実探索を確認した構成を同梱した。54ケースすべての新規実探索と最終TESTは完了していないため、95%の全条件合格版とは扱わない。旧v0.3.4にはこの追加分は含まれない。

Unity Hubではこのリポジトリの `unity` を開き、Mainシーンを再生する。シーン選択からC01〜C06を選び、台数と「投入：上空＋開口」を設定して「散布・探索を開始」を押す。シーン選択内の「地形も変える」は、床の欠損・層間隔・瓦礫と、ノード・人物の配置を更新する。上部の「配置を変える」は地形を維持してノード・人物の配置を更新する。層の重なりはドラッグで側面へ回り込み、ホイールで拡大して確認できる。
